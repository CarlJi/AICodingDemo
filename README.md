# AICodingDemo

这是一个现代化的响应式单页网站示例。

## 功能特点

- 🎨 现代化的渐变色设计
- 📱 完全响应式布局，支持各种设备
- ✨ 流畅的动画效果
- 🔗 平滑滚动导航
- 📝 联系表单

## 使用方法

### 本地预览

1. 克隆仓库到本地
2. 使用浏览器打开 `index.html` 文件

或者使用本地服务器：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 网站结构

- `index.html` - 主页面
- `style.css` - 样式文件
- `script.js` - JavaScript 交互脚本

## 网站包含的部分

1. **首页** - 醒目的欢迎横幅
2. **关于我们** - 展示核心优势
3. **服务** - 提供的服务项目
4. **联系我们** - 联系表单

## 技术栈

- HTML5
- CSS3 (包含 Grid 和 Flexbox 布局)
- 原生 JavaScript (ES6+)

## 自定义

您可以轻松修改以下内容：

- 在 `style.css` 中更改颜色主题
- 在 `index.html` 中修改文本内容
- 在 `script.js` 中添加更多交互功能
